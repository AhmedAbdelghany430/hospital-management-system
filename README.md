# Hospital Management System

A simple hospital management web app built with HTML, CSS and vanilla JavaScript. Data is saved in the browser with localStorage, so there is no backend.

## Features
- Dashboard with counts of patients, doctors and appointments, plus upcoming appointments
- Add, search and delete patients
- Add and delete doctors
- Book appointments, with a check that blocks double-booking a doctor at the same time
- Mark appointments as completed or cancel them

## Tech
HTML5, CSS3 (Flexbox, Grid, responsive layout), JavaScript ES6, localStorage

## Run
Open `index.html` in a browser.
